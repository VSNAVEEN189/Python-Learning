django automatically looks for css file 
=============================================================================
To load the css file inside the template we need to use tag load 
1. {% load static %}
2. <link rel="stylesheet" href="contains link of file">
3. Used to inject css file content which inherits from base.html {% block css_files %}

To add a link use static tag or an image
4. {% block css_files %}
    <link rel="stylesheet" href="{% static 'blogs/app.css' %}">
{% endblock %}

Finding IP : by cmd - ping website name

To connect to server we also need port number.
2. Port - It is an communication endpoint, Each device has its own ports , Each ports functions differently.
IP is Residential address, Port Number is house number.
IP states the server which we want to connect, Port states the location on server which we need to connect.
Kind of a usb port

Port Number     Protocol / Service (Full Form & Purpose)
20	          FTP – File Transfer Protocol – Used for transferring data files between client and server
21	          FTP – File Transfer Protocol – Used for command control during file transfer
22	          SSH – Secure Shell – Provides secure remote login and encrypted communication
23	          Telnet – Teletype Network – Remote login service that sends data as unencrypted text
25	          SMTP – Simple Mail Transfer Protocol – Used for sending and routing emails
53	          DNS – Domain Name System – Translates domain names (like google.com) into IP addresses
67, 68	          DHCP – Dynamic Host Configuration Protocol – Automatically assigns IP addresses to devices in a network
80	          HTTP – Hypertext Transfer Protocol – Standard protocol used for loading web pages on the internet
110	          POP3 – Post Office Protocol Version 3 – Retrieves emails from a mail server to a client device
119	          NNTP – Network News Transfer Protocol – Used for distributing and retrieving Usenet news articles
123	          NTP – Network Time Protocol – Synchronizes time between computers on a network
143	          IMAP – Internet Message Access Protocol – Allows accessing and managing emails directly on the server
161	          SNMP – Simple Network Management Protocol – Used for monitoring and managing network devices
194	          IRC – Internet Relay Chat – Protocol used for real-time text messaging/chat
443	          HTTPS – Hypertext Transfer Protocol Secure – Secure web communication using encryption (TLS/SSL)

3.Sockets - Endpoint in communication flow between two program running over a network, They allow communication between two different processes running on the same machines
Socket address = IP address + Port number , To establish a connection between two ports is done by socket.
Steps involved:
1. Create a socket for communication.
2. Bind it with IP address and the port number of the receiver.
3. Sends a message via socket.

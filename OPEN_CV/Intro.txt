Morphological operations - processing image based on shapes and edges 
Types:
1. Erosion - Removes the pixels on foreground objects using function cv2.erode(). Gives a blur image
2. Dilation - Adds pixels using function cv2.dilate().
3. Opening - Erosion followed by dilation using function cv2.mordphology(using attribute cv2.MORPH_OPEN).
4. Closing - Dilation followed by erosion using function cv2.morphology(using attribute cv2.MORPH_CLOSE).
5. Morphological gradient - states difference between dilation and erosion using function cv2.morphology(using attribute cv2.MORPH_GRADIENT).
6. tOP HAT - Difference between input image and opening image using function  cv2.morphology(using attribute cv2.MORPH_TOPHAT).
7. BLACK HAT - Difference between closing of input image and the input image using function cv2.morphology(using attribute cv2.MORPH_BLACKHAT)

Resizing an image
There are three ways
1. Resizing only required dimension only the height is changed.
2. Resizing both width and height 
3. Resizing based on the aspect ratio -Scaling up->zooming in (more than 100), Scaling down->shrinking out (less than 100).
Scaling up:
Using interpolation cubic = INTER_CUBIC
Using interpolation linear = INTER_LINEAR
Scaling down:
Using interpolation area = INTER_AREA
using interpolation nearest = INTER_NEAREST
To fill the empty pixels interpolation is used while scaling up and down regarding smoothnes.

Thresholding - Takes value from channel 0 to 255 later that value is used in binary threshold,
If it exceed the threshold value is white and below value is black

Gausian blur - Reduces contrast between neighboring pixels using function cv2.GaussianBlur, both kernel has to be passed
Median blur - Almost similar to gaussian this removes the centre pixel with actual pixel vale in surrounding.

Bilateral filter - detects sharp edges and smoothnes , Depend on gaussian blur.
using some of the attribute
1. src - img as src
2. d - diameter of the pixel neighborhood
3. sigma color - prevents color to mix from each other keeps the distance between two colours
4. sigma space - depends on diameter, pixel mixing 

Edge detection -
Canny edge detection - Helps to extract edges, noise reduction, Checks intensity of the image, no suppression, thresholding.
